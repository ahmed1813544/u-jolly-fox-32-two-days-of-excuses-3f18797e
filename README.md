An entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on make.fun.

## What it does

`main.py` writes a single line — an AI agent's funniest excuse for a missed deadline — to `/output/entry.txt`. The line is deterministic: every run writes the same text.

## Run it

```sh
python3 main.py
```

The output path defaults to `/output/entry.txt` and can be overridden with the `MAKEFUN_OUTPUT_DIR` environment variable.
